# منابع گرافیک و صدای رایگان و قانونی

> قانون طلایی: **قبل از دانلود هر چیزی، لایسنس آن را بخوانید.** فقط چیزهایی را استفاده کنیم که اجازهٔ استفاده در **بازی تجاری** را می‌دهند. هیچ مدل، صدا یا عکسی را از بازی‌های دیگر (مثل پابجی) برنمی‌داریم.

## ۱. منابع اصلی (مخصوص Unreal)

| منبع | چه چیزی دارد | لایسنس | کجا |
|---|---|---|---|
| **Lyra Starter Game** | سرباز، انیمیشن تفنگ و کلت (دویدن، نشانه‌گیری، شلیک، خشاب‌گذاری)، مدل چند سلاح، افکت شلیک | رایگان برای پروژه‌های Unreal | Epic Launcher → Fab → «Lyra» |
| **Game Animation Sample** | صدها انیمیشن حرکت حرفه‌ای (Motion Matching) | رایگان برای پروژه‌های Unreal | Epic Launcher → Fab → «Game Animation Sample» |
| **MetaHuman** | ساختن صورت و بدن واقعی برای سرباز اصلی (مثل کاور) | رایگان برای پروژه‌های Unreal | metahuman.unrealengine.com |
| **Fab.com** | هزاران مدل. هر ماه چند پک حرفه‌ای **رایگان** می‌شود و برای همیشه مال شما می‌ماند | هر آیتم را جدا بررسی کنید (Standard License برای بازی مناسب است) | fab.com → فیلتر **Free** |

**پیشنهاد:** هر ماه به Fab سر بزنید و پک‌های رایگان آن ماه را «Add to My Library» کنید، حتی اگر الان لازم نیست.

## ۴. یک نکته دربارهٔ کاور بازی

در کاور، هلیکوپترها و ماشین‌ها شبیه مدل‌های واقعی آمریکایی‌اند. برای پوستر مشکلی نیست. ولی **داخل بازی** شکل وسایل نقلیه را کمی متفاوت طراحی می‌کنیم، چون شکل دقیق بعضی وسایل نظامی واقعی علامت تجاری دارد.
