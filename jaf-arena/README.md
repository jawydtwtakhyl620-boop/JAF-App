# JAF Arena

بازی بتل‌رویال (Battle Royale) سه‌بعدی برای **وب، اندروید و آیفون**، با یک کد مشترک.

> «JAF Arena» نام موقت است و بعداً با نام نهایی عوض می‌شود.

## تکنولوژی

| بخش | ابزار |
|---|---|
| زبان | TypeScript |
| گرافیک سه‌بعدی | [Three.js](https://threejs.org) |
| ساخت و اجرا | [Vite](https://vitejs.dev) |
| اپ اندروید و آیفون | [Capacitor](https://capacitorjs.com) (همان بازی وب را داخل اپ اجرا می‌کند) |

همهٔ مدل‌ها، تصویرها و صداها با کد ساخته می‌شوند و هیچ فایل کپی‌شده‌ای در پروژه نیست.

## مرحلهٔ ۱ (انجام شده)

- نقشهٔ ۳۲۰×۳۲۰ متر با ۹ روستا، خانه‌هایی که می‌شود داخلشان رفت، انبار، درخت، سنگ، جعبه و دو جاده
- بازیکن با دوربین سوم‌شخص: راه رفتن، دویدن، پریدن و نشانه‌گیری (زوم)
- ۵ سلاح: Rook Pistol، Viper SMG، Falcon AR، Hammer Shotgun و Longbow Sniper
- ۴ نوع فشنگ، باند و جعبهٔ کمک‌های اولیه
- جمع‌کردن غنیمت و دو جای سلاح
- ۲۴ ربات دشمن که می‌گردند، بازیکن را می‌بینند، تعقیب می‌کنند و شلیک می‌کنند
- هدشات، نشانگر برخورد گلوله، فهرست کشته‌ها، و صفحهٔ برد و باخت
- کنترل لمسی برای موبایل (جوی‌استیک و دکمه‌ها) و کنترل کیبورد و موس برای کامپیوتر

## کنترل‌ها

**کامپیوتر:** WASD حرکت · Shift دویدن · Space پرش · کلیک چپ شلیک · کلیک راست نشانه‌گیری · R پر کردن خشاب · F برداشتن · 1 و 2 (یا Q) عوض کردن سلاح · 4 باند · 5 جعبهٔ کمک

**موبایل:** سمت چپ صفحه برای حرکت (اگر جوی‌استیک را تا آخر بالا بکشید، می‌دوید) · سمت راست برای چرخاندن دوربین · 🔥 شلیک · 🎯 نشانه‌گیری · ✋ برداشتن · ⇄ عوض کردن سلاح · R خشاب · ⤒ پرش · 🩹 باند · 💊 جعبهٔ کمک

## اجرا روی کامپیوتر (وب)

پیش‌نیاز: [Node.js](https://nodejs.org) نسخهٔ ۲۰ یا بالاتر.

```bash
cd jaf-arena
npm install
npm run dev
```

بعد آدرسی را که نشان می‌دهد (مثلاً `http://localhost:5173`) در Chrome باز کنید. اگر گوشی به همان وای‌فای وصل باشد، می‌توانید آدرس Network را در گوشی هم باز کنید.

برای ساختن نسخهٔ نهایی وب: `npm run build`. خروجی در پوشهٔ `dist/` است و می‌شود آن را روی هر هاستی گذاشت.

## ساختن اپ اندروید

پیش‌نیاز: [Android Studio](https://developer.android.com/studio)

```bash
cd jaf-arena
npm install
npm run android
```

Android Studio باز می‌شود. گوشی را با کابل وصل کنید (USB Debugging روشن باشد) و دکمهٔ ▶ Run را بزنید. برای انتشار در Google Play از منوی **Build → Generate Signed App Bundle** استفاده کنید.

## ساختن اپ آیفون

پیش‌نیاز: **کامپیوتر مک** با [Xcode](https://developer.apple.com/xcode/). برای نصب روی گوشی واقعی و انتشار در App Store، **حساب Apple Developer** (سالانه ۹۹ دلار) هم لازم است.

```bash
cd jaf-arena
npm install
npm run ios
```

Xcode باز می‌شود. در بخش **Signing & Capabilities** تیم (Team) خود را انتخاب کنید و ▶ Run را بزنید.

## ساختار کد

```
src/
  main.ts            شروع برنامه، منو و صفحهٔ پایان
  style.css          ظاهر HUD و دکمه‌های لمسی
  game/
    game.ts          حلقهٔ اصلی بازی، تیراندازی، آسیب، برد و باخت
    world.ts         ساختن نقشه (خانه‌ها، درخت‌ها، سنگ‌ها)
    player.ts        حرکت بازیکن و مدل آدمک
    bots.ts          هوش مصنوعی ربات‌ها
    weapons.ts       مشخصات سلاح‌ها و کیف (Inventory)
    pickups.ts       غنیمت‌های روی زمین
    input.ts         کیبورد، موس و کنترل لمسی
    hud.ts           نمایش جان، فشنگ و غیره
    effects.ts       ردّ گلوله و جرقه
    audio.ts         صداهایی که با کد ساخته می‌شوند
    physics.ts       برخورد با دیوارها
android/             پروژهٔ اندروید (Capacitor)
ios/                 پروژهٔ آیفون (Capacitor)
```
