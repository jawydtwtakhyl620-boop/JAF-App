# JAF-X — بازار آنلاین افغانستان

با JAF-X مردم در ولایت خودشان خرید و فروش می‌کنند. دکانداران آنلاین می‌فروشند و سودا را به خانهٔ مشتری می‌رسانند. کسانی که در خارج هستند هم می‌توانند برای خانواده و فامیل خود خرید کنند.

## امکانات
- **ثبت‌نام با تذکره:** نام، شماره تلفن، ولایت، آدرس، نمبر تذکره و عکس آن. قبول کردن شرایط و قوانین الزامی است.
- **دو نوع حساب:** شخصی و دکاندار.
- **قانون ولایت:** هر کس فقط آگهی‌های ولایت خودش را می‌بیند و فقط در همان ولایت می‌فروشد.
- **کاربران خارج از کشور:** ولایت تحویل (جای خانواده) را انتخاب می‌کنند و فقط خرید می‌کنند.
- **بازار:** جستجو، دسته‌بندی‌ها و آگهی عکس‌دار.
- **ارتباط:** پیام داخل اپ، تماس و واتساپ با فروشنده.
- **خرید آنلاین از دکانداران:** پرداخت آنلاین یا پرداخت هنگام تحویل. دکاندار «ارسال شد» و «تحویل داده شد» را ثبت می‌کند.
- **کیف پول دکاندار:** پول فروش آنلاین جمع می‌شود. دکاندار کد برداشت می‌گیرد و پول را با تذکره از نمایندگی نقد می‌گیرد.
- **ظاهر:** طراحی موبایل، فارسی و راست‌چین، با حالت تاریک.

## ساختار
```
index.html            صفحهٔ اصلی
css/style.css         طراحی
js/app.js             صفحه‌ها و رابط کاربری
js/data.js            ولایت‌ها، دسته‌بندی‌ها، شرایط و قوانین
js/rules.js           قوانین اپ (ولایت، خرید، کیف پول)
js/store-local.js     حالت آزمایشی (ذخیره در مرورگر)
js/store-firebase.js  حالت واقعی (Firebase)
js/config.js          تنظیمات Firebase
firestore.rules       قوانین امنیتی دیتابیس (قانون ولایت روی سرور)
storage.rules         قوانین امنیتی عکس‌ها (عکس تذکره محرمانه)
```

## حالت آزمایشی
تا وقتی `js/config.js` خالی است، اپ در حالت آزمایشی کار می‌کند و همه‌چیز فقط در همان مرورگر ذخیره می‌شود. یک حساب دکاندار نمونه هم دارد:
شماره `0700000001`، رمز `123456`.

اجرا:
```
python3 -m http.server 8000
```

## وصل کردن به Firebase (حالت واقعی)
1. در [console.firebase.google.com](https://console.firebase.google.com) یک پروژه بسازید.
2. **Authentication → Sign-in method** را باز کنید و **Email/Password** را فعال کنید.
3. **Firestore Database** و **Storage** را بسازید.
4. محتوای `firestore.rules` و `storage.rules` را در بخش **Rules** هر کدام بگذارید، یا دستور `firebase deploy` را اجرا کنید.
5. در **Project settings → Your apps** یک Web app بسازید و تنظیمات آن را در `js/config.js` بگذارید.

## کارهای باقی‌مانده
- **درگاه پرداخت واقعی** (HesabPay / M-Paisa / Atoma). یک Cloud Function باید پس از پرداخت، سفارش را «پرداخت شد» کند. تا آن وقت در حالت Firebase فقط «پرداخت هنگام تحویل» فعال است.
- **پنل مدیریت:** تأیید تذکره‌ها، تأیید برداشت‌ها در نمایندگی، و بستن حساب متخلفان.
- **تأیید شماره با SMS.**
