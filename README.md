# فروشگاه JAF

فروشگاه آنلاین ساده و سبک، بدون نیاز به نصب یا build. با HTML، CSS و JavaScript ساده نوشته شده و روی گوشی و کامپیوتر کار می‌کند.

## امکانات
- نمایش محصولات و دسته‌بندی‌ها
- جستجوی محصول
- سبد خرید (در مرورگر ذخیره می‌شود)
- فرم ثبت سفارش
- راست‌چین (فارسی)، واکنش‌گرا و حالت تاریک

## ساختار
```
index.html        صفحه‌ی اصلی
css/style.css     ظاهر
js/products.js    فهرست محصولات (محصول جدید را اینجا اضافه کنید)
js/app.js         منطق فروشگاه و سبد خرید
```

## اجرا
فایل `index.html` را در مرورگر باز کنید، یا:
```
python3 -m http.server 8000
```
و بروید به `http://localhost:8000`.

## انتشار رایگان با GitHub Pages
در GitHub: **Settings → Pages → Branch** را روی شاخه‌ی اصلی و پوشه‌ی `/ (root)` بگذارید.

## قدم‌های بعدی

- پنل مدیریت محصولات
- درگاه پرداخت
- عکس واقعی محصولات
